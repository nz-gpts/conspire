# Conspire

Evidence-first semantic forensics: reconstruct how words and phrases originate, change meaning, propagate through public discourse, and behave as signals in AI/security research.

## Reference case

The first reference case is **conspiracy**. It is a test case, not a hard-coded special case.

## Research layers

1. **Lexical ancestry** — inherited, borrowed, derived and cognate relationships.
2. **Semantic history** — meanings attested at different dates, kept separate from ancestry.
3. **Primary evidence** — dated quotations/documents with provenance and confidence.
4. **Public occurrence** — frequency through books, news, web corpora and other dated public sources.
5. **Change points** — detect statistically unusual increases, decreases and vocabulary substitution.
6. **AI/security research** — terminology mutation, adversarial phrasing, prompt-injection/jailbreak vocabulary, threat-intelligence search expansion and LLM semantic failure analysis.

## Evidence rule

A graph edge is not proof of a historical meaning. A frequency spike is not proof of cause. A linguistic similarity is not attribution. Claims must remain linked to their source evidence.

## Initial upstream sources

- Etymology Tree
- etymology-db
- Etymonline-derived datasets

The project will add primary historical corpora and public-occurrence datasets rather than treating any etymology database as ground truth.
